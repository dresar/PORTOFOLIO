  <p>WiFi publik tanpa password berisiko tinggi terkena serangan <em>Evil Twin</em> dan <em>Man-in-the-Middle (MitM)</em>. Peretas membuat jaringan tiruan dengan nama mirip kafe untuk mencegat kredensial login, cookie sesi, dan data finansial. Selalu gunakan VPN, matikan opsi <em>Auto-Connect</em>, dan hindari transaksi perbankan saat menggunakan WiFi umum.</p>
</div>

  </div>
  <p class="text-muted-foreground leading-relaxed">Siapa yang tidak menyukai koneksi internet gratis saat nongkrong di kafe? Namun, jaringan WiFi terbuka tanpa proteksi sandi sering kali menjadi umpan mematikan yang dipasang oleh penjahat siber. Saat perangkat terhubung tanpa enkripsi, seluruh lalu lintas data berpotensi dipantau oleh pihak ketiga yang berada di jaringan sama.</p>
</div>

<div class="slide-card my-8 p-6 rounded-2xl border border-border/60 bg-card shadow-xs">
  <h3 class="text-xl font-bold text-foreground mb-3">Slide 2: Modus Operandi Evil Twin Attack</h3>
  <div class="overflow-hidden rounded-xl my-6 border border-border/40 shadow-sm bg-muted/20 max-w-[420px] mx-auto">
    <img src="https://cdn.jsdelivr.net/gh/dresar/PORTOFOLIO@main/public/uploads/articles/05-wifi-gratis/05-wifi-gratis_02.png" alt="Slide 2 - Modus Operandi Evil Twin Attack" loading="lazy" class="w-full max-h-[480px] object-contain mx-auto" />
  </div>
  <p class="text-muted-foreground leading-relaxed"><em>Evil Twin</em> adalah teknik di mana peretas membuat Access Point (AP) palsu menggunakan SSID yang identik atau sangat mirip dengan nama WiFi resmi kafe. Ketika perangkat Anda secara otomatis terhubung ke jaringan palsu bersinyal lebih kuat ini, peretas dapat mencegat, mengandakan, dan merekam setiap paket data yang dikirimkan.</p>
</div>

<div class="slide-card my-8 p-6 rounded-2xl border border-border/60 bg-card shadow-xs">
  <h3 class="text-xl font-bold text-foreground mb-3">Slide 3: Data Sensitif yang Terancam</h3>
  <div class="overflow-hidden rounded-xl my-6 border border-border/40 shadow-sm bg-muted/20 max-w-[420px] mx-auto">
    <img src="https://cdn.jsdelivr.net/gh/dresar/PORTOFOLIO@main/public/uploads/articles/05-wifi-gratis/05-wifi-gratis_03.png" alt="Slide 3 - Data Sensitif yang Terancam" loading="lazy" class="w-full max-h-[480px] object-contain mx-auto" />
  </div>
  <p class="text-muted-foreground leading-relaxed">Melalui jaringan terinferensi, penyerang dapat menangkap token sesi (session cookies), username, password akun sosial media, hingga kredensial belanja online. Dengan teknik <em>SSL Stripping</em>, situs bertanda HTTPS bahkan bisa dipaksa turun menjadi HTTP tidak aman untuk mencuri plaintext password Anda secara <em>real-time</em>.</p>
</div>

Batasi penggunaan jaringan publik hanya untuk aktivitas umum seperti membaca berita atau browsing konten non-sensitif.</p>
</div>

<div class="slide-card my-8 p-6 rounded-2xl border border-border/60 bg-card shadow-xs">

Selain itu, matikan fitur <em>Auto-connect to open networks</em> di pengaturan WiFi HP atau laptop agar perangkat tidak otomatis tersambung ke titik akses jahat di sekitar Anda.</p>

<section class="my-8">
  <h2 class="text-2xl font-bold text-foreground mb-4">🔬 Analisis Teknis &amp; Fakta Lapangan</h2>
  <p class="text-muted-foreground leading-relaxed mb-4">
    Dalam arsitektur jaringan nirkabel IEEE 802.11, perangkat klien secara berkala memancarkan <em>Probe Request</em> untuk mencari Service Set Identifier (SSID) dari jaringan yang pernah terhubung sebelumnya. Perangkat peretas (seperti Wi-Fi Pineapple) memanfaatkan mekanisme ini dengan secara otomatis membalas <em>Probe Response</em> palsu, mengklaim sebagai jaringan resmi yang dikenali oleh perangkat korban.
  </p>
  <p class="text-muted-foreground leading-relaxed mb-4">
    Setelah terhubung, peretas dapat melancarkan aksi <strong>Man-in-the-Middle (MitM)</strong> menggunakan teknik <em>ARP Spoofing</em> atau menjalankan server DNS palsu. Meskipun enkripsi TLS/HTTPS telah menjadi standar web modern, peretas dapat memanipulasi lalu lintas menggunakan <em>SSL Stripping</em> atau menyajikan Sertifikat Root buatan via portal tertambat (<em>Captive Portal</em>) palsu yang meminta korban menginstal profil sertifikat tertentu sebelum mengakses internet.
  </p>
</section>

<div class="checklist-box my-8 p-5 rounded-xl border border-emerald-500/30 bg-emerald-500/5">
  <h3 class="text-xl font-bold text-emerald-600 dark:text-emerald-400 mb-3">🛡️ Checklist Langkah Praktis</h3>
  <ul class="space-y-2 list-disc list-inside text-muted-foreground">
    <li>Nonaktifkan fitur <strong>Auto-Join / Auto-Connect</strong> jaringan terbuka di smartphone dan laptop.</li>
    <li>Selalu aktifkan enkripsi end-to-end melalui <strong>VPN terpercaya</strong> sebelum melakukan transmisi data di WiFi umum.</li>
    <li>Gunakan koneksi <strong>Data Seluler / Mobile Hotspot pribadi</strong> saat mengakses m-banking atau aplikasi finansial.</li>
    <li>Periksa alamat domain pada address bar browser untuk memastikan awalan <strong>https://</strong> tanpa peringatan sertifikat SSL.</li>
    <li>Konfigurasikan fitur <strong>Two-Factor Authentication (2FA)</strong> berbasis authenticator app untuk seluruh akun krusial.</li>
  </ul>
</div>

<section class="my-8">
  <h2 class="text-2xl font-bold text-foreground mb-4">❓ Pertanyaan yang Sering Diajukan (FAQ)</h2>
  <div class="space-y-4 text-muted-foreground">
    <div class="p-4 rounded-xl border border-border/40 bg-card">
      <strong class="text-foreground text-base block mb-1">Apakah aman pakai WiFi publik jika situs yang dibuka sudah menggunakan HTTPS?</strong>
      <p class="text-sm leading-relaxed">HTTPS mengenkripsi isi data, namun peretas di jaringan yang sama masih dapat melihat domain mana yang Anda kunjungi via SNI/DNS query, serta berisiko terkena serangan SSL Stripping jika tidak ada proteksi HSTS.</p>
    </div>
    <div class="p-4 rounded-xl border border-border/40 bg-card">
      <strong class="text-foreground text-base block mb-1">Bagaimana cara membedakan WiFi asli kafe dengan Evil Twin?</strong>
      <p class="text-sm leading-relaxed">Secara kasat mata sulit dibedakan karena SSID dan MAC Address bisa dipalsukan (spoofing). Cara terbaik adalah mengonfirmasi langsung detail koneksi kepada staf atau menghindari WiFi tanpa otentikasi WPA2/WPA3 Enterprise.</p>
    </div>
    <div class="p-4 rounded-xl border border-border/40 bg-card">
      <strong class="text-foreground text-base block mb-1">Apakah VPN gratis aman digunakan untuk mengamankan WiFi publik?</strong>
      <p class="text-sm leading-relaxed">Banyak layanan VPN gratis memonetisasi pengguna dengan menjual data log lalu lintas internet. Sebaiknya gunakan provider VPN berbayar dengan kebijakan <em>No-Log Policy</em> yang telah diaudit independen.</p>
    </div>
  </div>
</section>
