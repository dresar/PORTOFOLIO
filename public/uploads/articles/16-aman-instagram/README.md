<div class="slide-card my-8 p-6 rounded-2xl border border-border/60 bg-card shadow-xs">
  <h3 class="text-xl font-bold text-foreground mb-3">Slide 3: Langkah 1: Gunakan Aplikasi Authenticator, Hindari 2FA SMS</h3>
  <div class="overflow-hidden rounded-xl my-6 border border-border/40 shadow-sm bg-muted/20 max-w-[420px] mx-auto">
    <img src="https://cdn.jsdelivr.net/gh/dresar/PORTOFOLIO@main/public/uploads/articles/16-aman-instagram/16-aman-instagram_03.png" alt="Slide 3 - Gunakan Aplikasi Authenticator" loading="lazy" class="w-full max-h-[480px] object-contain mx-auto" />
  </div>
  <p class="text-muted-foreground leading-relaxed">Pindahkan verifikasi dua langkah Anda ke aplikasi seperti Google Authenticator atau Duo Security. Jalur SMS rentan terhadap serangan SIM Swap yang kerap dimanfaatkan peretas untuk mencegat kode One-Time Password (OTP).</p>
</div>

<div class="slide-card my-8 p-6 rounded-2xl border border-border/60 bg-card shadow-xs">

</div>

<section class="my-8">
  <h2 class="text-2xl font-bold text-foreground mb-4">🔬 Analisis Teknis &amp; Fakta Lapangan</h2>
  <p class="text-muted-foreground leading-relaxed">
    Secara arsitektur keamanan, peretasan Instagram jarang terjadi melalui pembobolan server Meta secara langsung. Sebagian besar kasus merupakan eksekusi serangan <strong class="text-foreground">Social Engineering</strong> dan <strong class="text-foreground">OAuth Access Token Hijacking</strong>. Metode phishing paling sukses mengeksploitasi kepanikan pengguna dengan mengirimkan pemberitahuan palsu terkait hak cipta yang mengarahkan ke situs penampung data (credential harvesting site).
  </p>
  <p class="text-muted-foreground leading-relaxed mt-3">
    Di samping itu, kelemahan pada 2FA berbasis SMS terletak pada protokol rekayasa sosial operator telekomunikasi (SIM Swapping). Penyerang dapat menduplikat kartu SIM korban untuk mengambil alih token verifikasi. Penggunaan Time-based One-Time Password (TOTP) via aplikasi Authenticator mengisolasi token keamanan ke level perangkat fisik pengguna, sehingga tidak dapat dicegat melalui jaringan seluler.
  </p>
</section>

<div class="checklist-box my-8 p-5 rounded-xl border border-emerald-500/30 bg-emerald-500/5">
  <h3 class="text-xl font-bold text-emerald-600 dark:text-emerald-400 mb-3">🛡️ Checklist Langkah Praktis</h3>
  <ul class="space-y-2 list-disc list-inside text-muted-foreground">
    <li>Aktifkan 2FA jenis App Authenticator (Google Authenticator / Duo Security).</li>
    <li>Simpan Kode Pemulihan (Backup Codes) di tempat aman offline.</li>
    <li>Periksa tab "Email dari Instagram" di aplikasi untuk memvalidasi pesan masuk.</li>
    <li>Putuskan akses aplikasi &amp; situs web pihak ketiga yang tidak dikenali di akun Meta Accounts Center.</li>
    <li>Perbarui kata sandi dengan kombinasi unik minimal 12 karakter alfanumerik &amp; simbol.</li>
  </ul>
</div>

<section class="my-8">
  <h2 class="text-2xl font-bold text-foreground mb-4">❓ Pertanyaan yang Sering Diajukan (FAQ)</h2>
  <div class="space-y-4">
    <div>
      <strong class="text-foreground font-semibold block mb-1">Mengapa 2FA SMS dianggap kurang aman dibanding Authenticator App?</strong>
      <p class="text-muted-foreground leading-relaxed">SMS rentan terhadap kejahatan SIM Swapping, di mana peretas memalsukan identitas Anda ke operator seluler untuk mengambil alih nomor telepon dan menerima kode OTP secara terlarang.</p>
    </div>
    <div>
      <strong class="text-foreground font-semibold block mb-1">Bagaimana cara membedakan email asli dari Instagram dan email phishing?</strong>
      <p class="text-muted-foreground leading-relaxed">Cek di aplikasi resmi: Pengaturan &gt; Pusat Akun / Keamanan &gt; Email dari Instagram. Jika e-mail yang Anda terima tidak terdaftar di menu tersebut, maka dipastikan pesan itu adalah phishing.</p>
    </div>
    <div>
      <strong class="text-foreground font-semibold block mb-1">Apakah aplikasi penganalisis unfollowers berbahaya untuk akun?</strong>
      <p class="text-muted-foreground leading-relaxed">Ya, sangat berisiko. Aplikasi tersebut meminta token OAuth atau session cookie akun Anda yang dapat disalahgunakan untuk mengambil alih kendali penuh tanpa sepengetahuan Anda.</p>
    </div>
  </div>
</section>
